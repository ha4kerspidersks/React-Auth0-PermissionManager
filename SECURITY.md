# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you identify an issue related to OAuth token storage, PKCE exchange, or role enforcement, please report it privately:

1. **Email:** [subhajit.kar.official@gmail.com](mailto:subhajit.kar.official@gmail.com)
2. **GitHub Security Advisory:** Submit a private report via the [Security tab](https://github.com/ha4kerspidersks/React-Auth0-PermissionManager/security/advisories/new).

Please do not open public GitHub issues for security vulnerabilities.
